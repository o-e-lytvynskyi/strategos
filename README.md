# Strategos

A real-time strategy layer for Minecraft: Java Edition 1.21.1 (NeoForge). Command a faction from
an RTS camera, gather from real forests and quarries, raise buildings block by block, train an
army, advance through the ages and defeat your opponent — or drop into first person and walk
among your own units.

Strategos is inspired by classic RTS games such as 0 A.D. and Age of Empires. It is not
affiliated with or endorsed by Wildfire Games, Microsoft or Mojang, and it contains no code,
data or art from those games.

## Status

Design complete; M0 "Foundation" was accepted on 2026-10-22, and M1 "Movement" is in progress
since 2026-10-22. The roadmap is approved up to the first playable version (M0–M6). See [docs/STATE.md](docs/STATE.md).

## Platform

- Minecraft 1.21.1, NeoForge 21.1.264 or newer, Java 21.
- No other mods required.
- Built with Gradle and ModDevGradle; the JDK is provisioned automatically.
