## Implementation facts that prevent repeated debugging

- `ServerPlayerMixin` only reduces vanilla pairing at RETURN; exact primary faction and current-cell visibility are authoritative. Co-op player slots are not faction numbers. Tracker refresh compares denied player bodies independently of core-unit visibility versions.
- Embedded mock viewers do not automatically get listener ticks. Bounds fixtures drive the **real** `player.connection.tick()` where required. A teleport during Player Post needs the public listener `resetPosition()` because the listener restores `firstGood*` after `doTick()`.
- Spectators touching unloaded neighbours skip `Player.tick/Post`. The existing server Post now provides the bounded backstop before replication/tracking/flush. The actual skipped-branch counterexample was red before this fix and passes afterward.
- The M6 visual fixture originally drifted to `(144,144)` and left a transparent minimap corner. Initial `edgePan=false` was later replaced by configuration loading. Final code maintains the required setting conditionally throughout the scenario, waits for actual camera arrival and complete client map chunks before freezing, and preserves every original 600/1,200-tick and 60-calm requirement.
