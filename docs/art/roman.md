# Roman antiquity

The lobby's civilisation control offers Roman art for each faction. Roman units use an
original wide humanoid skin and a gold border and stripe on the faction-dyed shield. The
palette keeps the role's armour, tools and silhouette. The neutral style remains available
for saved matches and the existing scenarios.

Seven built-in building blueprints use light sandstone and quartz masonry with red
terracotta tile. They retain their dimensions, doors, spawn markers and damage ranks.
The same materials are used for staged construction, damage particles, repair and restore.
Crops use their original growth states. Blueprints and their Roman materials run through the
same registry lint. Command-card icons use registered vanilla items from the existing
template, technology and action definitions.

## Assets and provenance

- textures/entity/roman.png is a 64 × 64 original pixel skin with the pinned Minecraft wide
  humanoid model's UV layout. Its hair, linen, leather and sandal pixels were drawn for this
  project. No vanilla image pixels are included.
- textures/gui/roman_badge.png is a 16 × 16 Roman faction badge, generated for this project
  with OpenAI ImageGen and packaged by nearest-neighbour sampling. Prompt: “Use case game
  asset, original pixel-art sprite for the Strategos Minecraft RTS mod. Generate a single
  square civilization badge for the Roman antiquity faction. One boldly readable symmetrical
  bronze laurel wreath, with a small warm terracotta shield at the center and a pale sandstone
  highlight. The silhouette must remain legible at 16 by 16 game pixels. Draw on an aligned
  low-resolution pixel grid with hard square pixels, restrained six-color palette, no
  anti-aliasing, no gradients, no text or letters, no insignia copied from any existing game.
  Flat orthographic UI icon with a 2-pixel clear border and otherwise genuinely transparent
  background. No floor, dropshadow, frame, props or decoration. This is an original neutral
  faction identity mark.”
- The original images are distributed under the project's existing terms. Banner patterns,
  armour, building blocks and command-card items are referenced from Minecraft at runtime.
