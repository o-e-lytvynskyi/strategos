# Provenance notes (QA-13, ADR-0005 §4)

Where each subsystem's behaviour, numbers and art come from. The rule behind it
([ADR-0005](adr/0005-clean-room-and-licensing.md)): no GPL or all-rights-reserved source is opened; the
behavioural notes in [research/](research/README.md) are the only input from 0 A.D. and the other RTS
references; every number is re-derived at Minecraft scale and carries its reason in the balance data; no asset or
data file is copied. The only adapted third-party code is **RVO2 2.0.3** (Apache-2.0), named in
[NOTICE](../NOTICE). Design decisions: [04-architecture.md](04-architecture.md) and [adr/](adr/README.md).

The balance numbers of every template and technology live with their reasons in
`mod/src/main/resources/data/strategos/strategos/balance/provenance.json` (one line per value; the generated
[balance/sheet.md](balance/sheet.md) shows them beside the numbers, and `BalanceSheetTest` fails while it is stale).
Below, "the balance data" means that file.

## What is not here

No row above uses code, data, textures, sounds or names from 0 A.D., Age of Empires or any GPL or
all-rights-reserved mod. A claim to the contrary is a clean-room breach to be reported
([ADR-0005](adr/0005-clean-room-and-licensing.md), [security](security.md)). The names of those games appear only as
inspiration credit in the README and in these notes; `checkNaming` keeps them out of the mod id, display name,
`neoforge.mods.toml`, README title and logo file names.
