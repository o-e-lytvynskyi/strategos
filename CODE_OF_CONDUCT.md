# Code of conduct

Strategos adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every space of the project: the repository, its issues and pull
requests, and any chat about it.

In short: be respectful and constructive, assume good faith, critique work rather than people,
and keep discussion about the project. Harassment, insults and personal attacks are not tolerated.

**Reporting:** write to the owner privately through GitHub (the profile linked in
[docs/people.md](docs/people.md)), or use **Security → Report a vulnerability** if it must stay
confidential. The owner decides on enforcement, from a warning to a ban from the project.
